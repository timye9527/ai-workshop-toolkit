# AI体验活动方案｜模拟教学示例

这些安排是教学假设，不代表实际工作坊时间、预算或已安排人员。

对象：20位职场新人。时长：90分钟。假设预算上限：1000元。目标：每人完成一份经核对的周报初稿。

| 时间 | 环节 | 产出 | 负责人 |
| --- | --- | --- | --- |
| 0–10分钟 | 说明目标、隐私与事实检查 | 确认练习规则 | 待分配 |
| 10–25分钟 | 演示语音输入与四句需求法 | 一条清楚的需求 | 待分配 |
| 25–45分钟 | 选择国内工具，输入模拟记录 | 周报初稿 | 每位参与者 |
| 45–60分钟 | 给具体反馈，修改一轮 | 修改版 | 每位参与者 |
| 60–75分钟 | 两人交换核对事实与状态 | 验收清单 | 两人小组 |
| 75–90分钟 | 分享成果与下一步练习 | 保存成果 | 待分配 |

## 预算项目

场地、饮用水、物料与备用费用均待询价，不编造实时价格。总额控制在1000元假设上限内，经主办方核对后再采购。

## 备用方案

网络不可用时使用事先准备的模拟周报与打印记录，进行需求改写和人工核对练习。投影不可用时改为小组展示。设备不足时两人共用，并避免输入私密资料。
